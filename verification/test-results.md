# Проверка MindFlow: аудиодвижок, «Мой микс» и «Сценарии»

Дата: 5 октября 2026 года. Исходный проект: локальный `MindFlow APP`, ветка `main`, HEAD `240c2408423dd96ee778afa19d1fb1b86002cbf3`. На момент копирования в рабочей папке были незакоммиченные изменения; проверялось их текущее содержимое, а не только указанный коммит.

## Способ проверки

Во временной папке создана отдельная копия Flutter SDK 3.38.5, исходников `lib/` и `test/`, ресурсов `assets/` и индекса Git. Зависимости разрешены командой `flutter pub get --offline`. Тесты запускались в этой копии с отдельными `HOME` и `PUB_CACHE`; рабочий проект не использовался как каталог сборки. Flutter tester требовал локальное соединение с `127.0.0.1`, поэтому итоговый запуск выполнен с доступом к loopback.

Команда итогового запуска:

```sh
flutter test --no-pub --reporter expanded --concurrency 1 \
  test/audio_engine_test.dart \
  test/soundscape_engine_test.dart \
  test/soundscape_config_test.dart \
  test/runtime_soundscape_arranger_test.dart \
  test/session_mix_config_test.dart \
  test/ambient_mix_profile_test.dart \
  test/favorite_mix_preset_test.dart \
  test/scenario_runtime_controller_test.dart \
  test/mix_flow_screen_test.dart \
  test/scenarios_flow_screen_test.dart
```
