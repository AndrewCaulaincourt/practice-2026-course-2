# Практика 2026 — 2 курс: MindFlow

Материалы учебной технологической (проектно-технологической) практики по MindFlow. Тема — подготовка аудиослоёв для генеративной сборки и микширования, донастройка аудиодвижка, форматы «Мой микс» и «Сценарии».

В MindFlow «генеративная сборка» означает составление меняющейся звуковой сцены из подготовленных аудиослоёв и вариантов.

## Что представлено

Индивидуальное задание состоит из десяти пунктов: подготовка аудио (3), донастройка движка (2), «Мой микс» (3), «Сценарии» (2). [Отдельные страницы заданий](evidence/tasks/) и [матрица подтверждений](evidence/README.md) показывают, где искать реализацию и какой материал пригоден для проверки каждого пункта. [Каталог аудио](evidence/audio-catalog.md) содержит фактические параметры файлов, [демонстрационные фрагменты](media/audio/README.md) позволяют прослушать четыре роли одного сета, а [протокол проверки](verification/test-results.md) фиксирует результат автоматических тестов.

Рабочий проект MindFlow и полная аудиотека находятся отдельно. В этот репозиторий не включён полный исходный код приложения; технические описания содержат относительные пути к файлам рабочего проекта для сверки с ним. Наличие функции в текущем проекте само по себе не устанавливает дату её разработки: календарные даты приведены в индивидуальном задании, а этот репозиторий представляет результат и материалы отчёта.
