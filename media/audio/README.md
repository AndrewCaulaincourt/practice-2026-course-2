# Демонстрационные аудиофрагменты MindFlow

В этой папке находятся пять коротких MP3-файлов для приложений к отчёту по практике: четыре отдельные дорожки состояния **Stress, set_03** и пример их совместного звучания. Микс служит иллюстрацией послойного сведения; он не является записью вывода приложения или точным воспроизведением его автоматизации.

| Файл | Содержание |
| --- | --- |
| `stress_set03_drone_excerpt.mp3` | Слой `drone` |
| `stress_set03_pad_excerpt.mp3` | Слой `pad` |
| `stress_set03_texture_excerpt.mp3` | Слой `texture` |
| `stress_set03_pulse_excerpt.mp3` | Слой `pulse` |
| `stress_set03_illustrative_mix.mp3` | Иллюстративный микс четырёх слоёв |

## Источник и обработка

Исходники прочитаны из `MindFlow APP/assets/audio/core_states/stress/set_03/` (`core_stress_*.flac`). Все четыре исходных файла имеют одинаковую длительность **304,761917 с** и формат **стерео, 48 кГц, 24 бит FLAC**. Для демонстрации взят один и тот же отрезок **60–85 с** каждой дорожки. Фрагменты сохраняют исходное соотношение уровней, поэтому тихие слои `texture` и `pulse` лучше слушать в наушниках.

Для иллюстративного микса применены коэффициенты `drone × 0,8`, `pad × 0,55`, `texture × 1,4`, `pulse × 1,0`, затем общий коэффициент `× 1,5` и ограничение пика до `0,9` полной шкалы. У всех файлов плавное начало **0,3 с** и завершение **0,5 с**. Дорожки экспортированы в MP3 **160 кбит/с**, микс — **192 кбит/с**; все файлы имеют длительность **25 с**, стерео, **48 кГц**.

Пять файлов проверены декодированием через FFmpeg/FFprobe: ошибок нет, длительность, число каналов и частота дискретизации соответствуют указанным значениям.

## Авторство

Автор практики подтверждает, что исходные аудиодорожки MindFlow, включая **Stress set_03**, принадлежат ему. Представленные MP3 подготовлены из его дорожек для демонстрации в отчёте.
